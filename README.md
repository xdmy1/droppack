# DropPack — landing page

Marketing site for DropPack — a SaaS for parcel + passenger transport companies
running routes between Moldova and Europe.

Single-page Next.js 15 (App Router) app, statically exported, with RO/RU
language switching via `next-intl`. No backend.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4 (CSS-first theming via `@theme`)
- shadcn-style primitives (Button, Accordion) + Radix UI
- `next-intl` for i18n (RO default, RU)
- Framer Motion (subtle scroll fade-up)
- `lucide-react` icons
- Web3Forms for the contact form

## Local development

```bash
npm install
cp .env.local.example .env.local   # then add your Web3Forms key
npm run dev
```

Open http://localhost:3000 — you will be redirected to `/ro/`. Switch to
Russian via the `RO | RU` toggle in the navbar (or visit `/ru/`).

## Contact form (Web3Forms)

The contact form uses [Web3Forms](https://web3forms.com) — a free service
that emails form submissions to whatever address you register the access
key with. No backend needed.

1. Go to https://web3forms.com
2. Enter `sales@droppack.md` as the destination email
3. Copy the access key
4. Paste it into `.env.local`:
   ```
   NEXT_PUBLIC_WEB3FORMS_KEY=your-key-here
   ```
5. Restart `npm run dev`

If the key is missing, the form shows a helpful "use WhatsApp / email
instead" message — it doesn't crash.

## Logo & icons

The source logo lives at `/logo.png` (project root). The icon generation
script reads it and produces every variant the page needs:

```bash
npm run icons
```

This produces, in `/public/`:
- `logo.png` — the raw logo (referenced by the navbar / footer)
- `favicon.ico` — multi-size 16/32/48
- `icon-192.png`, `icon-512.png` — PWA / web manifest icons
- `apple-touch-icon.png` — 180×180 for iOS
- `og-image.png` — 1200×630 social preview (logo on brand background)

Re-run `npm run icons` whenever `/logo.png` changes. The script is idempotent.

## Build

```bash
npm run build
```

Outputs a fully static site in `/out/`. `next.config.ts` is set to
`output: "export"` so the `out/` directory can be uploaded to any static
host (Vercel, Netlify, S3+CloudFront, plain Nginx).

## Deploy to Vercel (one click)

1. Push the repo to GitHub.
2. Go to https://vercel.com/new and import the repo.
3. Vercel auto-detects Next.js. The only env var you need is
   `NEXT_PUBLIC_WEB3FORMS_KEY` — set it in **Project Settings → Environment
   Variables**.
4. Add the `droppack.md` domain in **Project Settings → Domains** and
   point your DNS A/AAAA records at Vercel's edge.
5. Deploy.

Because `next.config.ts` uses `output: "export"`, Vercel will simply serve
the static export. You can deploy the same `out/` folder anywhere else.

## Project structure

```
app/
  layout.tsx              # passthrough root layout
  page.tsx                # / → redirects to /ro
  [locale]/
    layout.tsx            # html / body / metadata / NextIntlClientProvider
    page.tsx              # the landing page (composes all sections)
i18n/
  request.ts, routing.ts, navigation.ts
messages/
  ro.json, ru.json        # all copy lives here
components/
  layout/Navbar.tsx, Footer.tsx
  sections/Hero.tsx, DashboardMockup.tsx, Problem.tsx,
           Solution.tsx, How.tsx, Pricing.tsx, Faq.tsx,
           FinalCta.tsx, Contact.tsx
  ui/Button.tsx, Accordion.tsx
  FadeUp.tsx, LanguageToggle.tsx
scripts/
  generate-icons.mjs      # logo → favicons + OG image
public/                   # generated by `npm run icons`
```

## Editing copy

All Romanian strings live in `messages/ro.json`, all Russian in
`messages/ru.json`. The two files have the same structure — keep them in
sync.

The dashboard mockup data (driver names, routes, statuses) is also in the
translation files under `hero.mockup.rows` so you can switch the demo data
per locale.

## Notes

- The accordion content uses keyframe animations defined in
  `app/globals.css` (`acc-up`, `acc-down`).
- Brand colors are defined as Tailwind v4 theme tokens in
  `app/globals.css` (`--color-brand-*`, `--color-accent-*`).
  Use `bg-brand-500`, `text-accent-500`, etc., as normal Tailwind utilities.
- The contact form includes a hidden honeypot field (`botcheck`) for
  Web3Forms' anti-spam.
